Description:
This website was designed as a study tool for Physics students, specifically AP Physics students at Thayer Academy. 
I studied a lot in AP Physics, which mostly involved redoing worksheets and test. I wished that there was a
website that could generate new examples so that I knew that I understood the principles, and not just memorizing
the solutions. I worked with my Physics teacher to choose ten examples to recreate; for each example, I created
animated simulations alongside 2-3 questions with randomized variables.
